  выполнялись и не нужны: проверка на маркерах покрывает тот же путь.

## Оставшиеся эксплуатационные вопросы

- Прошлые образы: собирались ли они из заполненного дерева и передавались ли
  кому-либо – по коду не установить. Если да, считать одноразовый пароль,
  секрет TOTP и TLS-ключ раскрытыми и заменить.
- TOTP по умолчанию не подключён (`totpEnrolled: false` при создании
  учётных данных); подключение – ручная правка `.admin-credentials.json`.
  Пока TOTP не подключён, знание пароля даёт полный доступ через форму
  входа – это штатное поведение, аудит его не оспаривал.
- Клиент `mailto`: какой почтовый клиент у менеджеров и как он показывает
  процентно закодированную часть адреса – не проверялось; старые записи с
  такими адресами теперь безопасны в ссылке, но остаются в журнале.
- Замечено попутно (не правилось): после `node scripts/build-landing.js`
  `index.html` расходится с HEAD в одной строке блока преподавателей –
  каталог обновлён 11.09 после последней пересборки лендинга. Блок top5 при
  этом совпадает побайтно; `index.html` возвращён к HEAD.
- Замечено попутно (не правилось): в двух из пяти полных прогонов
  `node --test tests/unit/*.test.js` воркер файла `prerender-landing.test.js`
  (съёмка через headless Chrome) после завершения тестов не выходил и
  прогон висел без нагрузки; поодиночке файл проходит за секунды, три
  прогона подряд зелёные. Файл не менялся. Запуск с
  `--test-timeout=180000` превращает такое зависание в провал вместо ожидания.
- Замечено попутно (не правилось): `renderTop5Data` ищет конец блока по
  первой `]` после `top5: [`; название программы со скобкой `]` сломало бы
  повторную сборку. Сейчас таких названий нет.
