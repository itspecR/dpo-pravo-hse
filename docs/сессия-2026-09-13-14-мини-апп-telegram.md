### Экраны

1. **Витрина:** «Факультет права НИУ ВШЭ», «Программы Центра ДПО», поиск, чипы «Все» + 6 сфер со счётчиками, карточки (обложка, пометки ПК/ПП и формат, название, цена, «Старт: …»). Каскад карточек только при входе вперёд.
2. **Программа – «А · Лента»**, пустые разделы не выводятся:
   обложка, пометки, название → «Важно» (только свежее) → факты (старт, формат, длительность, объём, язык, график, документ) → цена со скидками и налоговым вычетом → «О программе» (лид как на сайте; описание свёрнуто до 6 строк или списком для склеенных) → «Кому подойдёт программа» → «Чему вы научитесь» → «Преимущества программы» → «Программа обучения» (модули раскрываются на подтемы) → «Документы программы» (PDF) → «Преподаватели-практики» (фото, справка на 3 строки, «Страница на hse.ru ↗») → «Отзывы выпускников» (листаются вбок) → «Документы для приёма» → «Вопросы и ответы». Главная кнопка «Подать заявку · <цена>».
3. **Заявка:** имя и фамилия из профиля Telegram, телефон, e-mail, должность и место работы (необязательно), согласие – непредустановленная галочка с текстом формы сайта; проверки и тексты ошибок = серверный `parseApplication`. Согласие сбрасывается между заявками.
4. **После отправки (демо):** «Демо: заявка не отправлена», сводка (программа, имя, телефон, e-mail, метка, откуда), главная кнопка «Перейти к оплате на hse.ru» (формула `buildPayUrl`).

### Данные на странице

Каталог встроен блоком `<script type="application/json" id="tg-data">`, каждый `<` экранирован. Тексты проходят `normalizeProgram` страниц программ (чистка, канон имён преподавателей из `lib/teacher-names.js`), длинное тире заменяется на короткое. Фильтры: фото преподавателей – только существующие файлы `images/teachers/`; страницы – только https на hse.ru; PDF – только наши копии в `files/`; объявление – только свежее (`isNoticeFresh`, 90 дней), ссылка только https. Служебные поля каталога не уходят. Данные около 300 КБ, по сети со сжатием около 70 КБ.

### Безопасность и Telegram

- CSP: `default-src 'none'; script-src 'self' https://telegram.org; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'none'; base-uri 'self'; form-action 'none'; object-src 'none'` – без `unsafe-inline`; разметка через `createElement`/`textContent`.
- `telegram-web-app.js` грузится с telegram.org без SRI (Telegram обновляет файл по тому же адресу).
- Свои скрипты и стили – с integrity и версией в адресе `?v=` (10 hex-знаков sha384); `build-public` пересчитывает версию по сжатым скриптам. Без версии закэшированный старый скрипт при новой странице блокировался бы SRI → пустой экран.
- Код мини-аппа данные заявки никуда не отправляет и не хранит. Скрипт Telegram сам держит в `sessionStorage` параметры запуска, включая `tgWebAppData` (id, имя, username пользователя).
- Внутри Telegram: `ready`, `expand`, цвета шапки/фона/нижней полосы `#FBF9F5` (с проверкой версии), нативные `MainButton` (`#1658DA`) и `BackButton`, `HapticFeedback`, внешние ссылки через `openLink`.

### Облик (записано в DESIGN.md, раздел «Мини-апп Telegram»)

Облик сайта целиком: кремовый фон `#FBF9F5`, HSE Slab в заголовках, HSE Sans в тексте, один синий акцент, без теней в покое, карточки 14px, кнопки 12px. ## 5. Решения, принятые без отдельного вопроса (и цена ошибки)

1. Работа в ветках, а не в `main` – цена: одно слияние.
2. Push и выкладка только после «да» владельца – цена: одно сообщение ожидания.
3. Миниатюры исправлены вопреки ошибке в плане – спецификация требует миниатюру.
4. Субагент добавил исключения impeccable без спроса – откачено; позже владелец разрешил, добавлено штатно.
5. Служебный ключ Telegram SDK в `sessionStorage` принят и описан в README – альтернатива (свой SDK) противоречит спецификации.
6. Локальный превью-сервер не переделан под адрес `/tg/` – локально открывать `/tg/index.html`.
7. Отложены: Enter вне Telegram не отправляет форму; нет подтверждения закрытия; нет DOM-тестов `tg-app.js`; подписи старта фиксируются при сборке (пересобирать перед выкладкой); «Читать полностью» решается по числу символов.
8. Объявление в карточке сделано синим, как на сайте, а не золотым, как в макете – правило DESIGN.md.

## 6. Как работать дальше

- **Пересобрать мини-апп:** `node scripts/build-tg-app.js` (после любой правки `js/tg-*.js` или `tg/tg-app.css` – иначе тест integrity упадёт).
- **Выложить витрину:** только из `main` после слияния: `npm run publish-mirror`, затем `git push mirror main`, дождаться `gh api repos/itspecR/dpo-pravo-hse/pages/builds/latest`, проверить в браузере.
- **Тесты:** не гонять полный набор в фоне – воркер `prerender-landing` зависает. На macOS нет `timeout`:
  - `perl -e 'alarm 540; exec @ARGV' node --test --test-timeout=120000 $(ls tests/unit/*.test.js | grep -v prerender-landing)`
  - `perl -e 'alarm 240; exec @ARGV' node --test --test-timeout=180000 tests/unit/prerender-landing.test.js`
  - после прерывания по времени проверять `pgrep -fl "node --test"` – остаются осиротевшие воркеры.
- **Проверка в браузере:** `playwright-cli -s=<имя> open …`; в zsh команду с сессией не класть в переменную (не разбивается на слова) – использовать функцию `pw() { playwright-cli -s=x "$@"; }`. Каждый раз свежая сессия: в старой кэш скриптов даёт ложную SRI-ошибку. `fetch` из страницы мини-аппа блокирует CSP – это не сбой.
- **Инструменты записи:** Write/Edit превращают escape-последовательности вида «обратный слеш, u, hex» в символы – в коде использовать `String.fromCharCode`, после правок проверять grep.

## 7. Открытые вопросы

1. **Проверка новой карточки на телефоне** владельцем (светлая и тёмная тема; если видна старая версия – закрыть и открыть мини-апп, кэш до 10 минут).
2. **Второй этап – настоящий приём заявок:** `POST` в `intake-server.js` с `initData`, проверка HMAC-подписи токеном бота и `auth_date`, заявка по тому же пути (журнал, письмо, вкладка «Заявки») с источником «Telegram» и меткой; уведомление менеджерам в чат; боевой HTTPS-адрес; в nginx разрешить фрейм `web.telegram.org` на `/tg/` (сейчас `X-Frame-Options DENY` и `frame-ancestors 'none'`).
3. **SRI + кэш на остальных страницах сайта:** страницы программ подключают скрипты без `?v=`, nginx отдаёт JS с `max-age=86400` – после выкладки возможна блокировка скриптов до суток. Решение уже есть в `lib/sri.js` (`version: true`), не включено для сайта.
4. **CI в GitHub:** оплатить или поднять лимит в Settings → Billing у Bogolubov-creator.
5. Удалённые ветки `feat/tg-mini-app` и `feat/tg-program-card` в origin можно удалить.
